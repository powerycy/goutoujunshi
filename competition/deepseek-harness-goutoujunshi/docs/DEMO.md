# 公开 Demo 演示脚本

全部姓名、sender ID、消息、时间与证据均为公开合成数据。

## 主路径（约 3 分钟）

1. 启动后展示空工作区：说明不强迫用户先上传聊天，普通叙述也能开始。
2. 点击“载入公开案例”：左侧出现“小北”和“阿岚”，内部 ID 分别稳定显示为 `obj_小北`、`obj_阿岚`。
3. 在“小北”对话页解释完整军师结构：
   - 先承接“已经投入又怕一厢情愿”的情绪；
   - 列出三条可观察事实；
   - 把判断标成合理推测；
   - 明确无法知道对方内心与未记录现实安排；
   - 给出“推进”建议、低压力邀约话术、48 小时观察窗口和停止条件；
   - 点击“确认这个行动”，强调不自动发送。
4. 切换到“阿岚”：页面显示 1 条独立关系记忆和 1 条证据，不出现“小北”的 3 条记忆与 5 条证据。
5. 切回“小北”→“关系进展”：依次悬停红、绿、灰蜡烛，讲清每条的事实、摘要、来源、完整度，以及“证据图不预测爱意或成功率”。
6. 点击“添加关系证据”：说明粘贴、截图/文件、ChatLab 和电脑只读均为用户按需选择。
7. 点击“演示跨批次身份冲突停止”：`contact_17` 已锁定为对象，新批次若标为用户，界面立即停止分析且不覆盖映射。
8. 点击“查看对象记忆”：暂停后页面不再允许新增，恢复后可添加一条公开演示记忆，再用“撤销”回退。

## 建档与五对象上限

从空工作区点击“建立第一个对象”，输入任意公开代号。重复建立到 5 个后按钮会拒绝第 6 个对象；改名只改变显示代号，不改变内部 ID。
