## 作品简介（500 字以内）

“狗头军师”是一款面向个人终端的关系决策 Agent，解决用户在暧昧、冲突、冷淡与投入失衡中“情绪很重、证据混乱、下一步难执行”的问题。项目以官方 DeepSeek Harness 为 Agent、会话、工具、插件和 Web UI 底座，将已开源的狗头军师 Skill 作为只读能力内核，通过适配层按需加载参考。用户可以临时询问，也可为最多 5 个稳定对象建立隔离档案；Agent 先承接情绪，再区分事实、合理推测与未知，给出可复制话术、观察窗口、停止条件，并由用户确认是否行动。关系进展以证据 K 线呈现：红色代表正向进展、绿色代表退缩或冲突、灰色代表证据不足，每根 K 线均可回看来源，不预测爱意或成功率。项目内置无需 API Key、无需真实聊天的公开合成案例，支持 DeepSeek API Key 接入，并提供身份锚点、防认反、跨对象记忆隔离、撤销与归档机制；不解密聊天数据库、不后台监控、不自动发消息。当前已完成可运行 Demo、桌面与移动端设计 QA、10 项自动化测试、只读边界校验及开源说明，可复用于其他高情绪个人决策场景。

## 任务闭环

1. 用户在普通对话中描述关系困惑，可选择临时询问或建立对象档案。
2. Agent 先承接情绪，再从输入中提取可观察事实，标记合理推测与未知。
3. 如输入聊天证据，系统先依据 sender/member ID 或用户确认的锚点锁定身份；冲突时立即停止。
4. Agent 给出推进、确认、修复或退出建议，以及可复制话术、观察窗口和停止条件。
5. 用户人工确认是否采用；系统不自动发送消息。
6. 后续证据进入当前对象的独立证据层，并在关系进展 K 线中保留来源引用。
7. 用户可更正、撤销、暂停记忆，或归档不再关注的对象。

## 核心创新

- **从生成答案到决策闭环**：建议必须带行动、观察窗口和停止条件，结果可继续验证。
- **证据而非情绪预测**：K 线只编码可回看的关系事件，不输出爱意、忠诚或成功率。
- **对象级隔离**：稳定对象 ID 是会话、记忆、证据和任务的分区键，最多 5 个对象，严禁串档。
- **防认反身份协议**：优先使用账号与会话元数据；元数据不足时要求锚点确认，跨批次冲突立即暂停。
- **垂直 Skill 的渐进式披露**：每次按现有 Skill 路由规则加载 1–3 份参考，降低长提示词噪声并保留可复用性。
- **真实 Harness 集成**：通过官方 profile、bundle、host tools 和 client slots 接入，不是仿 Harness UI。

## 当前进展与验证证据

- 公开合成案例无需 API Key 和真实聊天，可演示完整闭环。
- DeepSeek API Key 与自定义模型提供方能力保留在官方设置中。
- 16 根证据 K 线支持 OHLC、价格轴、成交量、十字线、悬停证据与右侧决策面板。
- 自动化测试覆盖对象上限、对象隔离、身份冲突停止、证据方向、记忆压缩/撤销、归档/恢复和只读适配。
- `pnpm run test:all`：10/10 通过；`pnpm run check:readonly`：通过。
- 浏览器 QA 覆盖桌面聊天、桌面 K 线、模型设置、归档流程与移动端布局。

## 安全与合规边界

- 公开仓库不包含真实聊天、凭据、Token、Cookie 或私密文件。
- 原始聊天属于本地证据层，不进入长期记忆；长期记忆仅保留五类精简记录。
- 不解密聊天数据库、不绕过系统权限、不后台监控、不自动发送消息。
- 高风险动作必须由用户确认；身份冲突、明确拒绝与安全风险均触发停止或转入安全路由。

## 开放与复用价值

项目将可复用能力拆分为 Harness bundle、插件、参考路由、身份与证据工具、记忆适配层以及安全协议。其他高情绪、低确定性的个人决策场景，可复用“事实—推测—未知—行动—观察—停止—确认”的闭环，而无需复制狗头军师完整素材库。
