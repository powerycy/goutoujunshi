# 数据、隐私与安全说明

## 演示数据

- `examples/goai_demo_scored.jsonl` 含 38 条公开合成消息，专为比赛评审与自动化测试生成。
- 合成案例不对应真实人物，不包含真实聊天、联系方式、账号、设备信息或精确位置。
- `/api/demo` 不需要 API Key，不向外部模型或第三方服务发起请求。

## 真实数据路径

- 本地 Skills 模式：用户在本机完成评分后导入结果；适合敏感聊天。
- API 模式：仅在用户主动选择、提供文件路径和 API Key 后调用所选模型；API Key 不写入浏览器本地存储，也不进入任务 ID、日志或磁盘路径。
- 浏览器历史记录不保存聊天文件路径；旧版本残留字段会在加载时清除。

## 决策边界

- 输出严格区分事实、推断和未知。
- 关系指数根据历史互动呈现升温、回落、冲突与修复趋势，用于评估未来是否还有推进空间；它是可能性判断，不是确定结局或心理诊断。
- 每个方案必须包含观察窗口和停止条件，以便用户验证或退出。
- 任何发送、关系确认或线下行动均要求用户人工确认；演示产品不代发消息。
- 明确拒绝、不适、胁迫、暴力、跟踪、诈骗、自伤风险等情形优先进入安全与专业支持流程，不使用普通推进话术。

## 可追溯性

每个演示方案保留以下链路：公开合成消息 → 消息级相对评分 → 周期趋势与关键事件 → 事实/推断/未知 → 用户目标 → 可逆行动。评委可从图表悬浮信息查看消息、主导维度、变化值与理由。
