# 90 秒演示脚本

## 0–15 秒：问题

“关系里最难的，通常不是缺一句高情商回复，而是刚受伤时，情绪、事实和猜测混在一起。狗头军师先接住，再判断。”

画面：首页主视觉，点“直接体验”。

## 15–35 秒：有限证据

“评委不需要登录。这里有三个匿名案例，也可以输入已经去敏的文字。演示环境不保存聊天，刷新或清除即消失。”

画面：依次划过三个匿名示例，选择“暧昧降温”，点击“开始拆解”。

## 35–58 秒：不是读心

“系统先把情绪落地，再把事实、合理推测和关键未知分开。然后看主动、兑现、边界和修复。它不会因为一次回复慢，就下结论说对方不爱了。”

画面：事实/推测/未知三栏和互惠雷达。

## 58–78 秒：真正的技术分支

“关键不只在生成一段话。切到‘边界预警’，威胁、强制定位和隐私曝光会触发另一条路径：暂停关系博弈，先保全证据、关闭权限、联系可信的人。”

画面：选择“边界预警”，点击“开始拆解”，展示红色风险卡和安全建议。

## 78–90 秒：产品判断

“狗头军师不把拿下某个人当作唯一胜利。它希望用户在情绪、自尊、互惠、安全和未来选择权之间，做一个更清醒的下一步。”

画面：停止条件、可复制文字和产品底线。
