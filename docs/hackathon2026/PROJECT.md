# 项目介绍

## 一句话

**狗头军师——内置13万字符关系知识与决策体系，解决亲密关系难题。**

## 真实问题

人在关系里最缺的通常不是一句“高情商回复”。真正难的是：刚受伤时情绪很满，事实、猜测和恐惧混在一起；朋友会站队，平台内容爱下结论，套路课则把“拿下对方”当成唯一胜利。

狗头军师先做一件看起来很慢、但更有用的事：把局面拆开。

1. 先接住用户此刻的感受，但不替未经证实的解释背书。
2. 把可观察行为、合理推测和关键未知分开，不读心。
3. 看双方的主动、兑现、边界和冲突修复，而不是只看一句话热不热。
4. 检查 PUA、控制、同意、安全和隐私风险。
5. 给一个现在能做的小动作、观察窗口和停止条件。

## 为什么不是另一个“恋爱话术生成器”

狗头军师不把让某个人答应当作唯一目标。它把情绪稳定、安全、自尊、互惠、时间精力、机会成本、长期信任与未来选择权一起纳入判断。

“强势”在这里指清楚边界和快速筛选，不是羞辱、威胁或控制。明确拒绝、僵住、躲避或撤回时，系统不会继续设计推进路径。出现威胁、跟踪、强迫或暴露隐私时，建议会从关系沟通切换到安全与支持网络。

## 评委版完成了什么

- 一个无需登录、无需测试账号的公网 Web 体验。
- 三个匿名场景，以及可粘贴去敏文字的自由输入。
- 情绪承接、证据分层、互惠雷达、风险检查、明确建议、停止条件和可复制文字。
- 高风险场景路由：不继续“教聊天”，先处理安全和隐私。
- 不写入数据库或浏览器存储；刷新或点击清除即可消失。
- 公开使用手册、封面、桌面/手机快照、自动测试和可复现知识统计。

## 技术实现与难点

Web 版把原 Skill 中散落在知识文件与实践指南里的判断边界，重构为浏览器端可解释决策层。它不是一条固定漏斗：输入中的持续失约、控制、拒绝、隐私威胁等信号会改变证据提示、风险级别、行动建议、停止条件和回复成品。

实现使用 TypeScript、React、Next.js/vinext 与 CSS。所有交互在浏览器内完成，既降低评委体验门槛，也避免演示环境保存真实聊天。项目通过产品行为测试，并在 1440px 桌面与 390px 手机视口完成视觉检查。

AI 参与方式如实说明：Codex 辅助完成代码实现、重构、测试、部署与报名材料整理；封面使用 OpenAI 图像生成。原始关系知识与产品判断沉淀在公开仓库中。

## 报名通道判断

选择**自助报名赛道**。官方明确为使用本地编程工具自部署的作品提供这一入口。现有项目不是扣子搭建产物；临时在扣子复刻再报名会牺牲完成度，也会带来搭建平台表述不准确的问题。独立 Web 版更符合现有技术事实，也能在截止日前把公网体验、手册、测试和隐私机制一次完成。
