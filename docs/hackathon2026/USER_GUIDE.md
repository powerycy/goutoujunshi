# 公开使用手册

在线版本：**【公网部署后回填】/guide**

评委不需要登录、不需要测试账号，也不需要安装任何内容。

## 60 秒体验路径

1. 打开在线版本，点击“直接体验”。
2. 选择“暧昧降温”“投入失衡”或“边界预警”任一匿名案例。
3. 点击“开始拆解”。
4. 依次查看：情绪承接、事实/推测/未知、互惠雷达、风险检查、明确建议、停止条件和可复制文字。
5. 推荐再试一次“边界预警”，观察系统如何切换到安全与隐私处置。

## 自己输入文字

可以粘贴一段已经去敏的关系困惑，最长 1,200 字符。请先删除姓名、电话、住址、公司、学校、账号、精确行程和私密影像信息。

## 如何读结果

- **事实**：只复述输入中能确认的行为和事件。
- **合理推测**：明确保留不确定，不把猜测写成对方内心。
- **关键未知**：只列真正会改变建议的信息。
- **互惠雷达**：比较主动、兑现、边界和修复行为，不给人做“人格总分”。
- **风险检查**：识别持续投入失衡、控制、同意和安全隐私风险。
- **明确建议**：包含现在能做的一步、观察窗口和停止条件。

## 隐私与清除

评委版不设账户，不使用数据库，也不使用 `localStorage` 或 `sessionStorage` 保存输入。文字只在当前页面内存中；点击“清除全部”、刷新或关闭页面即可清空。

内置案例是产品演示文本，不是真实聊天。

## 安全边界

- 不提供贬低、服从测试、嫉妒操控、煤气灯、孤立、跟踪或性施压方案。
- 明确拒绝、僵住、躲避或撤回时，应立即停止推进。
- 出现威胁、跟踪、强迫或隐私曝光时，优先安全处置和可信支持。
- 即时人身危险应联系当地紧急服务。

## 限制

这是关系决策辅助原型，不替代心理、医疗或法律专业服务。它不能确认未提供的线下行为、语气和动机，不诊断心理疾病，也不保证某段关系会按用户希望发展。
