# 狗头军师微信小程序“狗头”定价方案

> 版本日期：2026-07-21。产品只支持文字输入和文字输出。

## 最终定价规则

- 正式版采用三档预付额度：**新人限定 ¥1/10 狗头、单题补给 ¥6/30 狗头、持续跟进 ¥12/75 狗头**。
- 新人限定包每名用户限购一次，付款门槛和单个狗头价格均为全场最低。
- **1 狗头 = 10,000 个成本折算 token**。
- 每次模型回答后，按照 API 返回的实际 token 用量计算狗头。
- 狗头只使用整数，不显示小数；每次扣费结果向上取整。
- 不对外宣传固定或“大约多少次对话”，因为实际次数由输入、历史上下文和回答长度决定。
- 付费狗头在服务持续运营期间无固定使用期限；活动狗头按活动规则到期。
- 支付尚未接入的封闭内测只展示新人限定方案：点击不会扣款，符合名额规则的用户获得 2 次免费完整分析，并预留正式版 10 个活动狗头；活动狗头发放后 60 天有效。

充值页建议文案：

```text
新人限定｜¥1 / 10狗头

先把一个最急的关系问题说清楚。
每次成功交付完整分析扣 1–3 狗头；没有交付，不扣狗头。
详细用量由实际输入、历史上下文和回答长度决定，可在计费明细中核对。
```

“1 狗头 = 10,000 个成本折算 token”及三类 token 权重放在可展开的计费说明中，不作为页面首要价值文案。

## 什么是成本折算 token

以阶跃 `step-3.5-flash` 为例，官方价格为：

| Token 类型 | 模型成本 |
| --- | ---: |
| 未缓存输入 | ¥0.70 / 百万 tokens |
| 缓存输入 | ¥0.14 / 百万 tokens |
| 输出 | ¥2.10 / 百万 tokens |

输出 token 的成本是未缓存输入的 3 倍，缓存输入是未缓存输入的 0.2 倍，因此不能把三类 token 当成同价 token。

换算公式：

```text
成本折算token = 未缓存输入token
              + 缓存输入token × 0.2
              + 输出token × 3

扣除狗头 = 向上取整（成本折算token ÷ 10,000）
```

因此，1 狗头分别相当于：

- 10,000 个未缓存输入 token；或
- 50,000 个缓存输入 token；或
- 约 3,333 个输出 token；或
- 上述三类 token 的混合用量。

来源：[阶跃定价与限速](https://platform.stepfun.com/docs/zh/guides/pricing/details)。

## 扣费示例

一次对话指“一次用户提问 + 一次模型回答”。系统提示词、关系档案、按需知识和历史消息都计入输入 token。

| 每轮情况 | 输入/输出示例 | 成本折算 token | 向上取整后扣除 | 10狗头理论可聊 |
| --- | ---: | ---: | ---: | ---: |
| 较短 | 4,000输入 + 600输出 | 5,800 | 1狗头 | 最多约10次 |
| 标准 | 6,000输入 + 1,000输出 | 9,000 | 1狗头 | 约10次 |
| 较长 | 10,000输入 + 2,000输出 | 16,000 | 2狗头 | 约5次 |
| 超长 | 20,000输入 + 3,000输出 | 29,000 | 3狗头 | 约3次，剩1狗头 |

所以 ¥1/10狗头不等于20次。由于每次至少扣1狗头，理论最多是10次；特别长的一次回答可能扣除多个狗头。

## 阶跃 step-3.5-flash 利润

标准一问一答按 6,000 输入 + 1,000 输出计算：

```text
单次模型成本 = 6,000 ÷ 1,000,000 × ¥0.70
             + 1,000 ÷ 1,000,000 × ¥2.10
             = ¥0.0063

10次标准对话模型成本 = ¥0.063
```

假设微信支付终端结构为 70% Android/鸿蒙/Windows、30% iOS，对应活动费率分别为 1% 和 12%，加权支付费约 4.3%：

| 项目 | 金额 |
| --- | ---: |
| 用户支付 | ¥1.000 |
| 支付费 | -¥0.043 |
| 10次标准对话模型成本 | -¥0.063 |
| 贡献毛利 | **¥0.894** |
| 贡献毛利率 | **89.4%** |

每个狗头最多承载10,000个成本折算token，因此10狗头完全用满时，阶跃模型成本上限约为：

```text
10狗头 × 10,000折算token × ¥0.70/百万 = ¥0.070
```

按该成本上限和4.3%支付费计算，¥1包贡献毛利仍约 **¥0.887，毛利率88.7%**。这里尚未扣除服务器、数据库、内容安全、退款、税费、客服和研发成本。

不同支付渠道下，按模型成本上限测算：

| 渠道 | 支付后贡献毛利 |
| --- | ---: |
| 全部 Android/鸿蒙/Windows | 约 ¥0.920，92.0% |
| 70% 前述渠道、30% iOS | 约 ¥0.887，88.7% |
| 全部 iOS | 约 ¥0.810，81.0% |

微信费率和活动资格会变化，应以上线时实际类目、终端和平台政策为准。来源：[微信虚拟支付技术服务费](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment/devplan.html)。

## Step Plan Flash Pro 不能默认用于收费小程序

`Flash Pro` 不是模型名称，而是 Step Plan 的专业版订阅套餐：官方标准订阅价为 **¥199/月**。当前页面列出的额度约为每5小时1,500个Prompt（约22,500次模型调用）、每周6,000个Prompt（约90,000次模型调用）。其中Prompt是平台的标准化计费单位，不等于一次小程序对话，官方仅说明通常15–20次标准请求约折算为1个Prompt。

来源：[Step Plan概览](https://platform.stepfun.com/docs/zh/step-plan/overview)。

若只做理论成本比较，按 `step-3.5-flash` 标准单次成本¥0.0063计算：

```text
Flash Pro 与按token付费的理论月度盈亏平衡点
= ¥199 ÷ ¥0.0063
≈ 31,587次标准对话/月
```

## 产品实现规则

- 充值页和首次计费确认完整展示折算公式、最少扣 1 狗头和单次硬上限；日常发送前不展示预计区间。
- 回答完成后读取 API 的实际 usage，计算成本折算 token，再向上取整扣除整数狗头。
- 每次最少扣1狗头，不存在0狗头调用。
- 模型未交付可用回答、超时或被安全层拦截时不扣用户狗头；模型方已经产生的费用由商家承担并记录。
- 用户端提供充值、消耗、退款和剩余狗头明细；回复处只展示本次扣费与余额，详细 Token 放在消费明细页。
- 购买狗头与赠送狗头分账，优先消耗赠送狗头。
- API Key 只保存在服务端，不能下发给用户或写进小程序代码包。

## 关键假设与风险

- 6,000输入 + 1,000输出只是标准示例，不是对话次数承诺。
- 向上取整会使短回答也至少扣1狗头，规则必须在充值前明确展示。
- 1狗头的价值绑定的是阶跃当前价格结构；模型涨价或切换供应商时需要提前公告新的折算规则。
- 未消费付费狗头属于尚未履行的服务义务，需要维护长期账本，并准备停服时的退款或迁移方案。
- 活动狗头必须显示发放时间和到期时间；本次创始内测活动固定为发放后 60 天有效。
