# 狗头军师｜手机 Demo

以网页方式承载的手机产品体验。首页、我的、充值、历史判断、加载与分析结果沿用微信小程序的视觉和交互；所有分析通过服务端真实链路完成，不包含 mock 回退。

## 体验链路

1. 打开链接后，网站自动向 `/v1/auth/web-demo` 获取 30 天演示会话，无需输入密码或个人资料。
2. 演示账号默认拥有 100 次完整分析额度。
3. 浏览器在 `localStorage` 保存限时会话 Token；服务端仍会校验签名与有效期。
4. 提交问题时生成唯一 `Idempotency-Key`，轮询任务直到交付、失败或安全拦截。
5. Enter 直接提交，Shift+Enter 换行；分析未交付不扣额度。

## 本地运行

Node.js 需要 `>=22.13.0`。

```bash
cp .env.example .env.local
pnpm install
pnpm dev
pnpm test
```

`BACKEND_API_URL` 必须指向稳定的狗头军师 API 根地址。它仅由 Sites 服务端代理读取，不打包进客户端。生产环境同时配置 `BACKEND_PROXY_KEY`，Sites 与后端之间使用加密信封传输。

## 安全边界

- 代理只允许手机 Demo 登录、额度查询、历史、建议和分析相关接口，不开放管理员成本接口。
- 自动登录只产生受限的演示身份，不下发服务端密钥或管理员凭证。
- 分析仍受服务端共享额度、每日尝试上限、幂等、单次 Token 硬上限和内容安全规则约束。
- 问题与结果继续沿用现有 API 的存储、额度与成本记录。
- 前端不包含模型密钥、微信密钥、会话签名密钥或永久管理员凭证。
